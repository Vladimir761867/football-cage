# ⚽ Дворовый футбол (football-cage)

Мобильная веб-игра про футбол во дворе. Портретная ориентация, управление одним жестом
«потяни и отпусти». Работает в любом современном браузере, без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере — или поднимите любой статический сервер:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

Для GitHub Pages: Settings → Pages → Deploy from branch → `main` / root.

## Режимы (все бесплатны)

| Режим | Суть | Победа |
|---|---|---|
| **Собачка** | 1/3, 1/4 или 2/5: пасующие держат мяч, водящие пытаются перехватить. 10 потерь — игрок выбывает | Последний игрок на площадке или лучший счёт за 90 сек |
| **Квадрат** | Квадрат делится на четыре части; игроки перебрасывают мяч. Два отскока в своей части или ошибка = штраф, 10 штрафов — вылет | Последний игрок на площадке |
| **Американка 300** | Гол 25, штанга 50, девятка 75, перекладина 100; направление, сила и тайминг удара | Первый до 300 против 1–3 соперников; есть тренировка |
| **Навес** | Четыре видимых игрока, подача и удар с лёта или головой. После промаха бьющий идёт в ворота; игрок может отбивать удары | Больше очков за 12 розыгрышей |

## Магазин

- **Классический двор** — бесплатно, доступен сразу.
- **«Россия, 90-е»** — платный косметический набор (панельки, берёзы, гаражи, лужи,
  фонарь, мел, облупленные ворота). В этой демо-версии покупка имитируется —
  реальные платежи не подключены.
- **Мячи по десятилетиям** — реалистичный атлас 80-х, 90-х, 2000-х, 2010-х и 2020-х за жетоны, которые даются за любые матчи.
- **Россия по десятилетиям** — 15 площадок: по три вида для 80-х, 90-х, 2000-х, 2010-х и 2020-х. Первый вариант каждой эпохи открыт бесплатно. Магазин фильтрует площадки по годам.

Честность: вся косметика меняет только картинку и звук. Физика мяча, окна тайминга
и правила одинаковы для всех — как в гейм-дизайн-документе.

## Структура

```
index.html        — экраны (DOM) + canvas матча
css/style.css     — стиль «бумага и мел», вечерний двор
js/save.js        — прогресс в localStorage (жетоны, покупки, рекорды)
js/sound.js       — синтезированные звуки (WebAudio) + вибрация
js/yards.js       — темы дворов, отрисовка сцен, исторические мячи, силуэты игроков
js/gesture.js     — единый жест «потяни и отпусти» (Pointer Events)
js/mode_dog.js    — «Собачка»
js/mode_square.js — «Квадрат» по четырём четвертям
js/mode_am300.js  — «Американка 300»
js/mode_cross.js  — «Навес»
js/main.js        — навигация, HUD, магазин, настройки, игровой цикл
assets/           — фоны 15 площадок, отдельные спрайты бегуна и вратаря, мячи по эпохам
```
