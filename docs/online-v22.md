# Как играть вместе

В меню «С друзьями» выберите формат и создайте комнату. Нажмите «Пригласить друзей» и отправьте ссылку. Она содержит код комнаты и, если нужен, адрес сервера. Друг может также ввести шестизначный код вручную. Игра начинается, когда все места заняты. У каждого участника свой экран, а очередь, время и счёт ведёт общий сервер.

| Формат | Участники | Правила |
|---|---:|---|
| Квадрат 1×1 | 2 | Поле поделено на две половины. Отбей мяч в половину соперника до второго отскока. Десять штрафов означают поражение. |
| Квадрат на четверых | 4 | У каждого своя четверть. Игрок выбывает на десятом штрафе. Побеждает оставшийся. |
| Американка 1×1 | 2 | Удары по очереди. После равного числа попыток побеждает игрок, который достиг 300 очков и опережает соперника. |
| Кубок американки | 2 | По три удара в сете. Две победы заканчивают матч досрочно. После трёх сетов выигрывает команда с большим числом побед. |
| Турнир американки | 4 | Два полуфинала и финал. По пять ударов каждому. При равенстве добавляется по одному удару с каждой стороны до преимущества. Ожидающие видят текущий матч. |
| Турнир квадрата | 4 | Три партии. За места начисляется 4, 2, 1 или 0 очков. При равенстве суммы учитывается число побед, затем место в последней партии. |

Можно создать онлайн-двор из редактора с текущим оформлением или открыть его через «С друзьями». Назовите двор и свою команду. Ссылка «Пригласить во двор» позволяет друзьям вступить под собственным названием. Участники видят комнаты этого двора, могут открывать свои и смотреть рейтинг. В ссылке на матч внутри двора есть приглашение во двор.

Рейтинг хранится отдельно для каждого двора и формата. Победа приносит три очка, ничья — одно. Завершённый турнир считается одним результатом. Игра в обычной комнате или в другом дворе эту таблицу не меняет. Название команды уникально внутри двора. Место команды сохраняется в браузере; при очистке данных браузера восстановление профиля пока не предусмотрено.

На главном экране можно переключить русский, английский, испанский, упрощённый китайский, португальский и хинди. Основная навигация, онлайн-лобби, правила на карточках и игровые подсказки переводятся. Часть длинных описаний каталога и заданий ещё на русском.

Для проверки на одном компьютере запустите `node server/rooms.cjs` и откройте `http://127.0.0.1:8000` в двух профилях браузера. Для постоянного доступа из интернета нужен один общий сервер Node.js с HTTPS и диском для рейтингов. Он может обслуживать игру целиком или работать отдельно от GitHub Pages. Для второго варианта укажите его адрес в `football-rooms-origin` в `index.html` и задайте на сервере `CORS_ORIGIN` для адреса игры. Если публичный адрес ещё не задан, его можно ввести при создании комнаты. Ссылки на комнаты уже включают этот адрес.
